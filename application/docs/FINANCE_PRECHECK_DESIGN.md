# 融资材料预审 Agent（竞赛实施说明）

## 目标与边界

RiskLens 新增的「融资材料预审」面向中小企业流动资金融资准备环节，输出仅包括：

- 已识别材料、缺少材料及文件可读性问题；
- 企业名称、法定代表人、统一社会信用代码等跨材料字段差异；
- 每条提示对应的文件、位置和原文摘录；
- 待补充材料与待人工核实问题。

系统不会输出授信审批、放款承诺、投资建议、保险赔付结论或替代专业机构的判断。结果状态恒为「需人工复核」。

## 竞赛闭环

1. 用户在知识库上传本人私有的企业材料。
2. 在融资材料预审工作台勾选一组材料。
3. 规则 Agent 对照流动资金预审清单分类，检查缺件、文件可读性和关键字段一致性。
4. 界面展示证据链、补件清单与人工复核问题。
5. 用户补件后再次运行，预审记录按用户隔离保存，便于演示前后变化。

## 当前规则清单

基础材料：营业执照、融资/借款申请、近期财务报表、纳税材料、银行流水/账户明细、主要交易合同、应收账款明细或账龄表。

条件材料：内部授权文件、担保/抵押材料。它们仅在具体融资产品或交易结构适用时提示，不计入基础材料缺件。

## 证据与数据处理

- 预审只接收当前登录用户自己上传的私有文档；共享法规和其他用户文件不能进入预审。
- 每个风险提示携带 `document_id`、文件名、页码/文本位置、字段标签和摘录。
- 当前规则采用确定性文本匹配与正则抽取，避免把未证实的模型推断伪装成事实。
- 扫描件未提取到文本、文件损坏或加密时，明确标记为「材料无法解析/缺少可检索文本」，交由人工处理。

## 后续增强顺序

1. 针对 PDF 表格增加行级抽取，使财务数字可定位到具体报表行。
2. 增加产品化清单版本、适用条件和制度来源；每项规则保留版本与生效时间。
3. 接入现有法规 RAG，形成金融合规问答的制度引用，但不得把检索结果转为审批结论。
4. 建立脱敏的金标准材料集，单独统计材料分类准确率、缺件识别精确率/召回率、字段冲突精确率、证据覆盖率与人工纠正率。

## 调研依据（仅作设计参考）

- [FinAgent RAG](https://github.com/mfarhan72/Fin-Agent)：金融文档分析采用规划、检索、分析和带引用输出的多 Agent 链路。
- [Agentic RAG](https://github.com/Rohianon/agentic-rag)：文档上传、风险标记、文件页码引用，以及表格不随意切分的处理方式。
- [Verified Citations](https://github.com/deepeshgupta12/agentic-rag-verified-citations)：逐条 claim-to-source 验证、冲突值显式呈现、默认拒绝访问未授权文档。
- [Agentic Financial RAG](https://github.com/MazkaB/agentic-financial-rag)：文本向量检索和数值结构化查询分离，并对引用与数值建立独立评测。

以上仓库为方法研究素材，不复制其代码或数据。
