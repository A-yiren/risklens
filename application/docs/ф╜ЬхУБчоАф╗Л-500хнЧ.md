# 作品简介（500 字以内）

## 律瞳 LegalLens — 律师/金融从业者的 AI 案件分析平台

**项目名称**：律瞳 LegalLens
**所选行业赛题**：GOAI 2026 · 无界应用（Boundless Agents） · **AI+金融**
**目标用户**：银行客户经理、保险理赔员、券商合规、投顾/法务、律师

**核心问题**：金融从业者面对"找法难、查案难、审合同难"三大痛点；通用模型可能生成无来源或错配来源的法律结论，且普通回答难以复核。

**解决方案**：律瞳以"多 Agent 协同 + RAG 检索 + 真实法规/判例库"为核心。
- **RAG 检索**：从 7 部金融法规（商业银行法/证券法/保险法/个人金融信息保护试行办法/征信业管理条例/理财业务监督管理办法/反洗钱法）+ 26 部法律 + 30 个金融判例 + 30 个法律判例中精准召回，每条观点必带 [n] 引用；
- **多 Agent 协同**：当前启用 A1 焦点识别 → A2 法律分析 → A3 引用核验；A4 风险评估在建立逐条证据校验前暂停输出；
- **4 大能力**：金融案件智能分析（60-90 秒）、判例检索（< 30 秒）、合同审查（20-30 秒）、法规浏览（< 1 秒）。

**创新点**：
1. 引用失败关闭：缺失、越界、未校验或部分失败的复合观点不会进入最终输出；当前尚无独立标注评测支持具体幻觉率承诺；
2. 不做训练、做 RAG——金融法规公开，RAG 实时更新、引用可溯源；
3. 核心原则：可验证、可追溯——每条观点能点开看官方原文。

**开放/复用价值**：RAG 与引用核验框架可推广至医疗、合规、审计；案例与法规种子数据在正式复用前需逐项验证来源、时效和授权。

**当前进展**：全栈开发完成并上线公网（https://ayiren.cn/legallens/），覆盖金融借款/信用卡/保险理赔/证券虚假陈述/银行理财 5 大场景。已通过生成式 AI 备案合规评估（7 份文档）。下一步对接银行 OA/保险核心系统 API。
