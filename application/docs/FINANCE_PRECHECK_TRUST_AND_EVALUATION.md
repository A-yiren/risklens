# 融资材料预审：可信边界与评测说明

## 产品边界

主场景为“企业流动资金融资材料预审”。系统只对用户主动选择、已入库的私有材料做四类工作：

1. 以 FPC-1.0 受控规则集比对基础材料是否被识别；
2. 提示文件不可解析或没有可检索文本的情况；
3. 从文本中抽取企业名称、法定代表人、统一社会信用代码等字段，并提示跨材料差异；
4. 将每一个命中结果回链至原文件、位置和摘录。

“材料已识别”仅表示关键词或字段命中，不能证明材料真实、完整、有效，也不代表满足任何金融机构的准入规则。结果始终为 `needs_human_review`，不输出授信审批、授信准入、放款、投资、保险理赔或正式法律意见。

## 可审计路径

每次执行返回 `reasoning_trace`。该字段是可复核的规则执行摘要，不包含模型隐藏推理：输入范围确认、材料规则匹配、字段/一致性比对、人工复核交接。前端将它与原始证据同时展示，使审阅人员可以从提示回到源文件核对。

金融合规问答沿用另一条来源控制路径：检索来源 → 焦点识别 → 参考分析 → 引用真实性校验。未通过引用校验的内容不进入结果；页面也明确说明输出只是参考，不能作为金融或法律决定。

## 量化评测

运行命令：

```bash
cd backend
python -m evals.evaluate_finance_precheck --output ../outputs/finance-precheck-internal-benchmark.json
```

基准数据 `evals/finance_precheck_benchmark_v1.json` 为三组去标识化合成文本，用来比较：

- 传统关键词检索基线：只判断关键词命中，不做跨材料字段一致性核验；
- RiskLens 规则预审：FPC-1.0 + 精确证据回链 + 字段一致性核验；
- 人工专家参照：预留为正式发布前的双专家独立标注与分歧裁决，当前尚未完成。

内部基准报告会输出受控预审规则召回率、错误引用率和重大风险漏检率。它不会把规则召回率称为“法规召回率”：当前预审使用的是产品受控规则，而不是已完成官方来源审计与双专家金标的法规语料。法规依据召回率在这些条件完成前必须显示为“暂不发布”。

## 对外公布前的必经检查

1. 两名互相独立的信贷或金融合规专业人员对冻结测试集独立标注；
2. 对分歧逐项裁决，保留版本、标注人角色和时间；
3. 法规语料逐条保留官方来源 URL、版本/生效状态和访问日期；
4. 固定检索参数、产品版本和数据集哈希，按相同测试集比较人工参照、传统检索/RAG 与产品；
5. 分场景公布法规依据召回率、错误引用率和重大风险漏检率，并同时公布样本量、置信区间和未覆盖边界。

在上述条件完成前，页面只可展示“内部规则基准”，不得宣称真实授信准确率、专家评测结果或法规准确率。
