# 双专家盲审执行包

该流程解决“人工专家参照”缺口，不能以 AI、项目成员自评或未核验标签替代。

1. 冻结 `FRR-0.1` 法规查询集和 `FPC-Benchmark-0.1` 材料场景，记录版本与 SHA-256；
2. 邀请两名互相独立、具备信贷风控或金融合规实务经历的评审，分别使用匿名编号 A、B；
3. 两人独立标注每个场景的应召回法规、重大风险、可接受证据以及“不应下的结论”；
4. 系统只在两份标注完整后开启裁决表；第三名负责人逐项记录一致、采纳 A、采纳 B 或新裁决；
5. 评审签署数据来源、角色、日期和利益冲突声明，形成不可覆盖的评审版本；
6. 只有完成上述步骤，才允许把对照实验标识由 `INTERNAL_ONLY` 改为 `EXPERT_REVIEWED`。

建议专家来源：合作银行普惠/授信风控人员、融资担保机构合规人员、企业法务中具备金融业务经验者。评审不接触真实客户隐私材料，只审阅去标识化冻结测试集。
