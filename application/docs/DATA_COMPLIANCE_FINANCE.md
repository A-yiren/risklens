# 融资材料预审的数据与合规说明

## 数据类型与来源

| 数据 | 来源/授权状态 | 处理方式 |
|---|---|---|
| 用户企业材料 | 用户主动上传的私有文件 | 仅限上传账号选择后使用；用于解析、规则核验与证据回链 |
| 评测材料 | 仓库内去标识化合成文本 | 不含真实客户数据；仅用于回归评测 |
| 官方法规目录 | 金融监管总局、人民银行公开发布的法规页面 | 仅保存名称、发布机关、生效时间、条目摘要和官方 URL |
| 大模型服务 | 由部署方在环境变量中配置 | 若启用外部模型，输入可能发送至该服务；部署方须审查服务条款与地域合规 |

## 最小化、权限与保留

- 预审接口仅接受当前登录用户已入库的私有材料 ID；其他用户文件和共享法规库不进入材料核验。
- 不将企业材料用作模型训练；不在常规日志记录原始材料文本。
- 用户应在上传前移除与预审无关的个人信息、商业秘密与敏感附件；生产部署应配置数据保留、删除和备份策略。
- 用户可在“规则与企业资料库”删除自己的私有原始材料；可通过预审记录删除接口删除自己的预审结果。删除不会影响共享法规库。

## 高风险边界

系统只提示材料完整性、可读性与跨材料事实差异。它不验证原件真伪、不判断财务真实性、不确定信用等级，也不作出授信审批、放款、投资、保险理赔或正式法律意见。每次结果固定标注 `needs_human_review`，由有权人员结合机构规则和原件完成决定。

## 可追溯性

每条材料命中、字段冲突和解析异常均保留文件名、位置和摘录。法规参考保留发布机关、条目、生效时间和官方链接；用户可回到源材料和官方页面复核。
