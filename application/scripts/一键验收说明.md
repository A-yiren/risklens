# RiskLens 一键验收模板

## 目标

用一次命令检查最容易影响评委体验的故障：核心文件缺失、后端语法错误、前端资源断链、线上页面不可访问、健康接口异常、主入口金融场景不一致、预审边界缺失与合同模板页缺失。

## Windows

```powershell
cd application
powershell -ExecutionPolicy Bypass -File .\scripts\一键验收.ps1
```

## Ubuntu / macOS

```bash
cd application
bash scripts/一键验收.sh
```

## 可选：完整后端回归

先在项目虚拟环境安装 `backend/requirements.txt`，再运行同一命令。脚本会自动追加 `pytest -q`；如果当前环境没有 pytest，会明确报告“警告”，不会伪造通过。

## 判定规则

- 任一“失败”：不建议对外演示，应先修复。
- “警告”：环境能力不足或可选回归未执行，需在部署环境补跑。
- 使用 `--report 路径/结果.json` 可写出 JSON 结果供答辩留档。
